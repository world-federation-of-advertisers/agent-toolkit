# halo-skills

Agent skills for consumers of the [Halo cross-media measurement](https://github.com/world-federation-of-advertisers/cross-media-measurement) API.

## Skill directory

Skills live under [`skills/`](./skills). Each is a directory containing a `SKILL.md` file. Claude Code auto-discovers them based on the `description` field in each skill's frontmatter.

## Adding a skill

See the top-level [`CONTRIBUTING.md`](../../CONTRIBUTING.md) and the [`SKILL_TEMPLATE.md`](./SKILL_TEMPLATE.md) in this directory.
